## Descrição

Este projeto é uma aplicação web voltada para o gerenciamento do fluxo de pedidos de *commissions*, sistemas de
pagamento, atualizações de status e atendimento de clientes, desenvolvida sob medida para um artista digital.

O projeto encontra-se em fase de desenvolvimento. Sinta-se à vontade para acompanhar o progresso e ler
a [documentação](./docs), onde foram estruturados diagramas e épicos de histórias de usuário (User Stories) para
auxiliar no desenvolvimento e simular um ambiente profissional de engenharia.

Caso deseje entrar em contato, estou a disposição nos meios de comunicação disponíveis no meu perfil do GitHub.
